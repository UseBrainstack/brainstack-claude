# Brainstack — universal plugin (macOS + Windows)

One Claude Code plugin, one native binary, both OSes. It provides the Brainstack
connector (query your brain) **and** the automatic capture hooks — no Node required.

## Install

```
claude plugin marketplace add UseBrainstack/brainstack-universal
claude plugin install brainstack@brainstack-universal
```

Restart Claude Code, approve the hooks once, and sign in to usebrainstack.com when
prompted. From then on your local sessions capture automatically.
